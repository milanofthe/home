PathView is a visual editor for [PathSim](/stack/pathsim/) and
[FastSim](/stack/fastsim/) models: drag-and-drop block diagrams, live
simulation preview, and instant sharing. It runs entirely in the browser via
Pyodide — nothing to install, nothing to license, nothing sent to a server.

![view.pathsim.org|right|46x14](/screenshots/view-pathsim-org.png)

Diagrams stay real PathSim models: what you edit visually is what runs in the
engine, and what you share is a model your colleague can open in Python. The
editor is also the reference for what I mean by scientific UI/UX — engineering
tools that run where the user already is, with no IT ticket between an idea
and a simulation.

## In the stack

PathView is the interface layer of the system level — the same role the
browser frontends of [RapidPassives](/stack/rapidpassives/) and
[RapidFEM](/stack/rapidfem/) play for fields.
